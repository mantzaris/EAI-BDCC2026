\section{Discussion and Limitations}

The study separates three operations that are often compressed into a single
notion of a reliable explanation: validating a newly generated answer, maintaining
an existing display after evidence changes, and producing a useful replacement
under load. Direct checks constrain fresh numerical content. Explicit dependencies
identify old content requiring attention. Generation then determines whether
the withdrawn information can be replaced with an adequate answer. Their costs
and failure modes must be measured separately. The paired reliability tables,
conditional correction denominators, and open-loop queues make these distinctions
observable rather than assuming that a graph or a citation solves all three.

The common symbolic fixture establishes the behavior of transitive maintenance
and alternative support for a known dependency structure. The generated waveform
task is narrower. Every numerical claim is encouraged to cite its operands
directly, limiting the number of situations where a transitive path provides
additional detection. A comparison statement can be withdrawn through its own
direct citation even when it also lists a parent claim. A benefit in a deliberately
deep fixture cannot establish a corresponding gain across naturally generated
multi-step interpretations. Conversely, a small difference between M1 and B2 in
this task does not prove that dependency depth never matters. Future studies
could prospectively vary depth and independent support while keeping candidates
and answerable facts matched.

Generated parent links are treated as declared prerequisites, not independently
proven necessary derivations. Redundant links can therefore cause withdrawals
under the contract even when a claim's direct source checks still pass. The
artifact report separately counts persistent claims whose only later error is
a declared parent dependency. The symbolic fixture provides a known necessary
transitive path; the waveform evaluation measures maintenance of the accepted
declarations, not the discovery of semantically necessary reasoning graphs.

The relational implementation is a substantive control, with indexes, recursive
traversal, the same immutable data, and the same support predicates. Logical
agreement supports attribution of maintenance behavior to the predicates and
dependencies, rather than to a graph product. The observed latency comparison
includes an in-process SQLite implementation and a local Neo4j service, a small
symbolic dependency structure, growing revision chains, and shared host resources.
It does not determine which storage engine wins for large distributed graphs,
concurrent writers, richer query patterns, or separately optimized deployments.
There is one 60-second cell per method and offered rate; the systems results are
descriptive measurements, not population-level statistical estimates.

Several measurement limits affect reliability claims. The numerical oracle is
independent code reconstructing immutable events, but it implements the same
published task contract. Agreement with a recorded value establishes source
faithfulness, not physiological truth. Lexical prose checks can miss an unsupported
interpretation or reject a semantically equivalent paraphrase. The smaller
automated verifier supplies additional evidence, but shares the generator's
model family, uses only 60 nonempty final outputs, and is tested on four simple
diagnostic examples. No human annotation gold standard was collected. Neither
exact checks nor the automated audit justify claims of unrestricted language
understanding, clinical safety, or comprehensive explanation fidelity.

The interventions are controlled replays at one severity. Missingness and offsets
are deliberately imposed on derived windows; they do not estimate the natural
prevalence of sensor faults. A hidden corruption cannot be detected with access
to an evaluator-only label, and our runtime never receives one. The waveform
matrix holds target event intervals fixed while knowledge changes across three
checkpoints. Historical/current scope and out-of-order arrivals are tested in
correctness fixtures, but the experiment does not cover every continuously moving
current-state query or long-term monitoring policy. The optional spectral features
are simple summaries without a physiological accuracy study, and no readiness,
stress-causation, or diagnostic classifier is evaluated.

Statistical precision is limited by ten held-out subjects per source and two
episodes per subject. Both real datasets use related wearable hardware and
collection traditions. Windows, variants, calls, and thousands of raw samples
do not create additional independent participants. Subject-cluster intervals
retain this dependence but cannot compensate for a small cohort, one generator,
one generation seed, or a restricted question contract. Conditional correction
rates additionally depend on what the method originally generated; the common
fixture is the stronger test of maintenance logic under identical candidates.

The interface demonstrates how a review action changes evidence and displayed
text. It does not certify that a reviewer-supplied value is true. The scripted
false-rejection example makes that distinction visible: a mistaken review can
remove valid content. Evaluating ranking policies, actual reviewer accuracy,
and review time would require separately designed studies. Likewise, deployment
policies for coalescing stale requests, retaining a useful prior answer during
replacement, and rechecking outputs immediately before publication remain
prospective engineering questions.

\section{Conclusion}

Temporal evidence maintenance makes revisions to generated monitoring explanations
inspectable and testable. Immutable versions preserve what an earlier answer
used, dependency predicates determine which statements require attention, and
alternative support prevents indiscriminate withdrawal. The completed evaluation
reports these behaviors alongside retained information, generated replacements,
and implementation cost on one synthetic and two real waveform sources. Its
scope is evidence-linked explanation maintenance. The relational control,
independent event-log evaluation, preserved failures, and explicit latency targets
keep claims about reliability and graph storage tied to measured outcomes.

\paragraph{Artifacts and reproducibility.}
The accompanying package contains the prospective plan, acquisition and split
manifests, frozen source/model hashes, raw generation and repair journals,
independent case scores, participant-level analyses, resource traces, and scripts
for every table and figure. Original recordings are obtained from their providers
under their recorded usage terms and are not redistributed with source code.
The package includes an executable local review demonstration and exact commands
for CUDA reproduction. The accompanying reproducibility report maps each written
result to its saved inputs and generation command.
