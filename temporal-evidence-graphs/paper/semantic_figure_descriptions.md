# Revised figure descriptions and data provenance

All main figures are generated by temporal_evidence.semantic.figures in
artifacts/figures/semantic_analysis_v1/, as vector PDF and SVG plus review PNG.
No generated raster art, random network or embedding plot is used.

1. **Ontology and construction.** A fixed type/relation subset is paired with
   the saved WESAD S11 episode: recording interval/sample count, EDA median,
   model claim, checking and subsequent feature version. The example values and
   timestamps come from the actual exported core. ontology_example.json records
   source hash and full observation/feature/claim IDs. The full construction table
   covers all stored types and relations, including assessments.

2. **Actual graph instances and revision.** WESAD and PPG-DaLiA median-size eligible
   correction cores, with fixed before/after positions and observation expansion.
   Blue arrows are stored citations; grey arrows record stored extraction or
   declared parent links. Orange dotted edges summarize current-version paths.
   Layout JSON preserves every ID and path witness. Both selected examples are
   shallow; the comparison also directly cites the changed operand. The
   maximum-impact selection rule independently chooses the same examples.

3. **Semantic structure.** Full-storage edge composition is separated from core
   type mixing, proposed/displayed zero-parent mass, active dependency in-degree,
   claim-parent depth and admissible witness count. C/F/O mean claim/feature/
   observation. SUPPORTS mirrors and membership hubs are excluded from reasoning
   degree. Distribution panels describe snapshot observations; uncertainty is
   calculated from episodes within dataset-scoped subjects.

4. **Semantic fidelity.** Independent grounding precision and required recall,
   separately for raw/final proposals and displayed fresh answers, then for
   previously displayed answers before arrival, after arrival and after recorded
   maintenance. Error and unresolved requirement fractions are their complements;
   underlying claim and requirement counts remain in the tables. Empty precision
   is undefined, while empty answerable output has zero recall. Discrete points
   are not interpolated latency or recovery curves.

5. **Theory under structural variation.** Exact compiled programs and actual
   admitted GPU programs separately plot the observed full/direct correction
   gap against independently derived exposure. Realized depth and route regime
   are encoded; the lower panels preserve missing roots and quantify root
   retention after primary-route loss. Denominators list exact/generated counts.
   Original admission is shown; the separate primitive-name correction is
   reported in the supplement, with unchanged candidate and link provenance.

The preserved four-panel streaming figure is in the supplement. Its generation
timings measure candidate completion, not adequate replacement: none of the
236 completed original candidates meets both required facts.
