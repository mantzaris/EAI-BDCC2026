# Current single-paper figure map

All five figures are generated by `temporal_evidence.semantic.figures`. PDF/SVG/PNG
outputs are in `artifacts/figures/semantic_analysis_v1/`; the manifest names only the
current set. Earlier network/topology exports are retained historical analysis
artifacts and are not submission figures.

1. **Ontology and construction** (`ontology_construction`). The researcher-defined
   vocabulary and a saved recording-to-feature-to-claim example distinguish
   deterministic construction, model proposals, validation and temporal insertion.
2. **Real revision network** (`real_revision_network`). One full-width WESAD S11
   episode-0 M1 correction graph from the actual Neo4j export. Seven stored records
   expose both source observation intervals, cited feature versions, the new EDA
   version and withdrawn numerical/comparison claims. All eight arrows are labeled;
   original citations stay attached to old versions. The comparison directly cites
   the corrected operand, so this example does not demonstrate a propagation gain.
3. **Generated witness network** (`structural_witness_network`). One full-width
   primary GPU-generated PPG-DaLiA S1 program, requested/realized depth two, selected
   from 87 eligible programs by smallest complete closure and lexical tie-break.
   An adverse revision withdraws CA while CB preserves the OR answer. Twelve stored
   records are visible, including eight rows in two AND witness enclosures. Dashed
   bundles explicitly map to the eight stored feature-citation edges; the remaining
   three stored edges are individually drawn. Enclosures/bundles are rendering
   constructs. Observation provenance can be expanded in the dashboard.
4. **Temporal semantic fidelity** (`semantic_fidelity`). Two readable panels retain
   grounding precision and required recall across the three observed revision
   checkpoints, with subject-level intervals. Methods/captions give denominators
   and explain arrival values inherited before maintenance. Fresh proposal,
   admission and displayed scores remain separately visible in the main table.
5. **Structural condition tested** (`structural_theory_test`). Two panels separate
   exact fixtures from generated programs, relating realized transitive exposure
   to direct-minus-full missed-change fraction. Root-depth distributions and
   alternative-route retention are reported concisely in main text/tables.

Network views, ID maps, source hashes, selection rules, before/after layouts and
stored-path witnesses are in `artifacts/analysis/review_views_v1/`. Dashboard and
publication rendering share the same typed objects. Human-readable edge labels
map exactly to relation names in the captions and manifests. Original assessments,
availability and display membership are separate; conflicting ties remain ambiguous.
The larger topology distributions and systems plot remain repository data. Candidate
completion latency is not adequate-replacement latency: the original systems
workload produced zero adequate replacements among 236 completed candidates.
