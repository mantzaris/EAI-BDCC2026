# Reference verification for the semantic revision

The existing bibliography was reused; the only new main-paper entry is PROV-DM.
The following primary sources were checked on 29 September 2026:

- Doyle, *A Truth Maintenance System*, Artificial Intelligence 12(3), 231–272
  (1979): [publisher record](https://www.sciencedirect.com/science/article/pii/0004370279900080)
  and [author archive](https://groups.csail.mit.edu/medg/ftp/doyle/).
- Gupta, Mumick and Subrahmanian, *Maintaining Views Incrementally*, SIGMOD 1993:
  [author project abstract](https://www.cs.umd.edu/projects/hermes/publications/abstracts/mvi.html)
  and [ACM record](https://doi.org/10.1145/170036.170066).
  The bibliography retains the conference DOI 10.1145/170035.170066; the SIGMOD
  Record publication uses 10.1145/170036.170066.
- Green, Karvounarakis and Tannen, *Provenance Semirings*, PODS 2007:
  [author-hosted paper](https://web.cs.ucdavis.edu/~green/papers/pods07.pdf).
- W3C, *PROV-DM: The PROV Data Model*, recommendation of 30 April 2013:
  [official specification](https://www.w3.org/TR/prov-dm/).
- Edge et al., *From Local to Global: A Graph RAG Approach to Query-Focused
  Summarization*, version 2 (2025):
  [paper record](https://arxiv.org/abs/2404.16130v2).
- Rasmussen et al., *Zep: A Temporal Knowledge Graph Architecture for Agent
  Memory* (2025): [paper record](https://arxiv.org/abs/2501.13956).
- Turpin et al., *Language Models Don't Always Say What They Think* (2023):
  [paper record](https://arxiv.org/abs/2305.04388).

PROV-DM is a conceptual positioning reference, not a claim that this property
graph is an RDF/OWL implementation. SHACL is not added as an implemented method.
Unused legacy entries remain in the source bibliography but are not cited in
the revised main narrative. Dataset/model references retain their original
acquisition/pinning manifests and bibliographic entries.
