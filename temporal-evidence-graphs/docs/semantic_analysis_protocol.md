## Semantic estimands

The new analysis reads immutable source events, never assessment flags, to decide
bounded numerical truth. It distinguishes grounding at the interval actually
asserted, coverage of answerable target requirements, and frozen contract
compliance. A background number must match its stated interval, subject, quantity,
unit and visible version. Merely citing a baseline while labelling the claim as
the target is still wrong. Declared prerequisites are audited separately from
the truth of directly checkable propositions. The protocol does not adjudicate
unrestricted prose; raw sentences, lexical discrepancies and the existing
imperfect verifier audit remain visible.

Canonical identity includes dataset, subject, session, event interval, quantity,
operation, normalized reference value and unit, temporal mode, and resolved
logical versions. Matching uses the frozen numerical tolerance. Each required
proposition is matched once. Precision uses emitted checkable propositions;
recall uses answerable required propositions. Empty output has precision NA and
zero recall/summary when requirements are answerable. Fully unanswerable tasks
have recall/summary NA and separately reported correct absence assertions.
The harmonic summary combines different universes and is not set F1.

Report proposals, accepted final-candidate claims, and displayed answers. For
maintenance, reuse the same previously displayed claims at three discrete
checkpoints: before arrival, after arrival before maintenance, and after recorded
maintenance. These are aligned positions, not interpolated latency trajectories.
Bootstrap subjects after averaging snapshots within episodes and episodes within
subjects (2,000 resamples, seed 20260929). Report denominators and empty cases.

## Prospective structural extension

Select the first five naturally sorted held-out subject IDs from each existing
source manifest and both existing episodes: 30 base episodes, reusing participants.
Cross four intended evidence-to-answer depths (1, 2, 3, 4) and two support regimes
(one route, two source-disjoint routes): 240 cases. Selection uses no new model
outcomes. The development pilot uses one existing development episode per source,
depths 1 and 4, both regimes: 12 cases, at most 24 calls.

Each route is a conjunction of four explicit tests of recorded EDA median, EDA
IQR, acceleration SD, and EDA missing fraction. Tests compare against supplied
numerical bounds; they make no physiological diagnosis. Bounds are constructed
from the two clean windows before inference so both routes initially satisfy the
same criteria. The primary route uses the target 30 s; the alternative uses the
preceding 120 s. Their underlying sample intervals do not overlap. Independence
means disjoint observation witnesses, not statistical independence or independent
sensors/participants. A route's EDA features share an observation and are not
counted as independent alternatives.

The answer is existential: at least one of the eligible windows satisfies all
four stated tests. In the single-route condition only the target is eligible.
Depth changes grouping, not the four tests or their bounds. Exact fixtures use
depth 1: direct tests; depth 2: route conjunction then answer; depth 3: prefix of
two, complete route, answer; depth 4: first test, prefix of two, complete route,
answer. Alternative routes have the same depth. These exact compiled programs
are labeled separately from generated programs.

The model receives evidence, proposition definitions and the requested grouping,
but may emit direct citations, omit parents or omit alternative witnesses. Never
insert missing model links. Its witness lists are OR alternatives of AND inputs;
each input is an explicit numerical test reference or a previously proposed
claim. Validation checks entailment by expanding the declared input meanings.
Record intended and realized depth, formula/witness fidelity and missing content.
Up to 16 claims and 4,096 output tokens are allowed; pilot may prospectively
adjust formatting/context limits before the core configuration is frozen.

For each common candidate and exact fixture, replay identical input events under
B0, B1, B2, M1 and B3: (i) necessary correction makes the first test false in
every route; (ii) loss of primary route only, leaving the alternative if present;
(iii) benign numeric correction that preserves the first test; (iv) a correction
to an unused cardiac feature. Conditions start independently from the same
baseline. Full methods schedule reverse-reachable claims; direct methods schedule
only direct neighbors; B0 schedules none. All use the same support predicates,
with no fresh generation during replay. SQLite uses indexed recursive CTEs;
Neo4j uses the existing adapter in isolated extension scopes.

The reference change set comes from task-defined propositions evaluated directly
against revised numeric events, independent of generated witness choices and
database assessments. Report exposure |A minus D|/|A| (NA if A empty), missed
changes, collateral withdrawal and surviving support. Separate failure to express
an admissible alternative from traversal failure. The sufficient-condition
prediction is evaluated only when initial claims and dependency semantics pass
the independently specified entailment check.

Run extension inference only after typed export, independent semantic scoring,
alternative-witness and necessary-dependency counterexample tests pass. Use the
existing RTX 5090 pod, pinned Qwen3-8B, CUDA parameters and forward tensors, no CPU
offload. One common candidate per case, at most one repair: at most 480 core
calls. Keep every raw response, failure, repair, prompt, hash and replay outcome.
No additional post-correction GPU generation is planned. Main benchmark GPU
requests are not repeated.

## Post-core normalization correction (29 September 2026)

The completed extension's admission table includes compound proposition names
but omits primitive test names as claim propositions. Some model outputs state
those explicitly defined comparisons correctly, yet lose them and dependent
roots to `unknown_proposition` / `unaccepted_parent`. Preserve that completed
run and its 209 admitted roots out of 240. The independent semantic scorer maps
a primitive test name to the comparator already supplied in the task, keeping
grounding separate from this admission restriction. A separately labeled
`primitive_alias_replication` repeats database maintenance with this explicit
normalization, the same final candidates and unchanged witness/parent tokens.
It makes no new GPU calls and does not alter either original results namespace.
Raw realized topology is retained, including undefined depths for malformed
references. The corrected replication is reported separately from the core.

## Development amendment and final analysis conventions

The original registered text is preserved as artifacts/runs/structure_study_v1/protocol_initial.md. The prospective pilot_amendment.json (08:44:57 UTC) adds pilot v2 before core outcomes, retaining both pilots (21 + 19 calls). The source freeze and request journal preserve the clarified core prompt.

Post-core analysis scopes participant identifiers by dataset when pooling sources; shared labels such as S2 do not identify one person across WESAD and PPG-DaLiA. This changes only new pooled uncertainty, not original results. The projection now explicitly honors historical proposition knowledge times; original generated waveform claims remain current-at-query-time.

Final provenance review found multiple trigger assessments sharing a record and
knowledge timestamp, sometimes with different states. The original graph lacks
a within-time assessment sequence. The new projection therefore preserves all
tied outcomes and marks conflicts ambiguous instead of selecting an arbitrary
first record. Original assessments remain unchanged. All semantic scores already
use independent event-log truth and saved display membership, so their results
are unaffected. The audit is exported separately and covered by a focused test.
